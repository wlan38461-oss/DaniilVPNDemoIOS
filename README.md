# DaniilVPNDemo (iOS)

Визуальный клон DaniilVPNapp для iPhone — тот же интерфейс, что и в
Android-версии (ввод ключа, экран подключения с кнопкой-таймером,
список серверов с флагами, переключатель VLESS/HYSTERIA2, экран
"Работает напрямую, без VPN"), но **без реального VPN** и **без
платежей/счётчика дней**.

## Отличия от Android-версии

- **Флаги — те же SVG**, что и в Android-версии (набор flag-icons),
  подключены через `Assets.xcassets` с `preserves-vector-representation`
  — Xcode рендерит их как векторное изображение при любом размере, без
  сторонних SVG-библиотек.
- **Экран "Работает напрямую, без VPN" — без вкладки "Приложения".**
  Apple не даёт приложениям получать список установленных на устройстве
  приложений (в отличие от Android). Остались только "Сайты" и
  "IP-адреса" — работают так же, хранятся локально через UserDefaults.
- Никакого реального VPN-туннеля, никакого NetworkExtension/Personal
  VPN entitlement — а значит, платный Apple Developer аккаунт **не
  нужен** даже для полноценного тестирования этой демо-версии.

## Сборка

Через GitHub Actions (`.github/workflows/build.yml`), как и в примере
с тестовым приложением: `xcodegen` генерирет `.xcodeproj` из
`project.yml`, дальше `xcodebuild archive` без подписи. Заберите
`.ipa` из артефактов сборки во вкладке Actions.

Это неподписанный `.ipa` — на настоящий iPhone его напрямую не
поставить (для этого нужна подпись через Apple ID, отдельный шаг).
